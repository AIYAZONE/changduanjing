# 长短经（反经）

> 唐·赵蕤 撰 · 九卷六十四篇 · 纵横谋略奇书

《长短经》为唐代赵蕤所撰，一名《反经》。博采诸子百家，融儒、道、法、兵、纵横于一炉，论为君之体、知人之道、经权之变、王霸之分，被誉为「小《资治通鉴》」。

## 书籍简介

《长短经》（一名《反经》），唐·赵蕤（ruí）撰。赵蕤字太宾，梓州盐亭人，博学韬钤，长于经世。与李白交厚，时称「赵蕤术数，李白文章」。

全书共九卷六十四篇：

| 卷次 | 篇目 | 主题 |
|---|---|---|
| 卷一 | 大体第一～量过第八 | 为君之体与知人之道 |
| 卷二 | 臣行第九～臣术第十一 | 臣道与用人 |
| 卷三 | 反经第十二～适变第十五 | 经权之辨 |
| 卷四 | 正论第十六～惧戒第二十 | 王霸之辨 |
| 卷五 | 七雄略 | 纵横捭阖 |
| 卷六 | 三国权 | 三国鼎立之鉴 |
| 卷七 | 惧戒二二～诡信二七 | 戒慎之道 |
| 卷八 | 息辩二八～运命三五 | 时运知命 |
| 卷九 | 出军～还师六十四 | 兵权谋略 |

核心思想：**「反经」**——反者道之动，正反相生，不以一端为定论。赵蕤立论不拘一家，以经权为纲、王霸为纬，论君体、辨臣行、审时势、量才德，处处讲究「因时而变、因地制宜」。
